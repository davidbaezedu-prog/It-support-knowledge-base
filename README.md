# 🖥️ Base de conocimientos de soporte de TI

Repositorio dedicado a la documentación de procedimientos técnicos, resolución de incidencias y buenas prácticas relacionadas con el soporte informático y la administración de sistemas.

El objetivo es mantener una colección organizada de guías prácticas que facilite el diagnóstico de problemas, la aplicación de soluciones y el aprendizaje continuo en el área de tecnologías de la información.

## 📚 Áreas de documentación

### 🪟 Windows
- Diagnóstico y resolución de problemas.
- Mantenimiento y optimización de equipos.
- Actualizaciones y configuración del sistema operativo.

🖧 Windows Server
- Conceptos fundamentales de administración de servidores.
- Configuración y mantenimiento de servicios.
- Documentación de procedimientos administrativos.

👥 Active Directory
- Administración de usuarios y grupos.
- Gestión de permisos y recursos de dominio.
- Conceptos de autenticación y políticas de grupo.

 ⚙️ PowerShell para soporte técnico

Documentación de comandos básicos de PowerShell aplicados al soporte de TI y la administración remota de equipos Windows.
Conexión y comprobaciones en equipos remotos.
Verificación de sesiones de usuarios en equipos remotos.
Ejecución de reinicios remotos autorizados.
Consulta de información del sistema para el diagnóstico de incidencias.
Documentación de comandos utilizados en tareas habituales de soporte técnico

 🛠️ Procedimientos técnicos
- Diagnóstico de incidencias.
- Documentación de soluciones.
- Validación de resultados y recomendaciones preventivas.

 🎯 Objetivos del repositorio

- Documentar soluciones a problemas técnicos frecuentes.
- Organizar conocimientos de soporte de TI y administración de sistemas.
- Practicar la documentación técnica profesional.
- Reforzar los conocimientos de ciberseguridad y buenas prácticas informáticas.
